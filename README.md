# poi-plugin-compass

面向 poi 的通常海域舰队罗盘。

## 功能

- 查看通常海域地图、节点类型、路线和各分歧点的前进概率。
- 根据当前舰队显示适用的带路条件，并突出当前生效的条件。
- 在能动分歧点手动选择路线；有阶段规则的海图会优先使用当前阶段的默认路线。
- 查看舰队的四组索敌值、制空值和经过战斗节点时的制空状态。
- 查看战斗节点的敌舰编成、出现比例、敌方制空线、舰船属性和装备。
- 将选定路线导出到 KC3Kai 或 noro6；有多个敌编成时可以分别选择。

## 安装

在 poi 的插件目录中安装：

```sh
cd "$HOME/Library/Application Support/poi/plugins"
npm install poi-plugin-compass
```

安装后重启 poi，在插件列表中打开「舰队罗盘」。

## 使用

1. 选择海图和当前使用的舰队。
2. 对有阶段的海图选择 P1、P2 或 P3。
3. 点击节点查看该点的带路条件和敌舰情报。
4. 点击能动分歧的路线或目标节点，指定前进方向。
5. 点击「导出」，选择路线和需要导入模拟器的敌编成，然后打开 KC3Kai 或 noro6。

地图空白处可以取消节点选择；取消选择后，右侧会显示当前海图的总体索敌和制空信息。

## 标记说明

- 绿色、红色和黄色图标分别表示带路条件当前满足、不满足或无法判断。
- 路线上的概率是到达该边的整体概率；带有 `?` 的数值表示资料不足时的近似值。
- `AL`、`AD`、`AP`、`AS`、`AS+` 分别表示空袭丧失、空袭劣势、空袭均势、空袭优势和空袭确保。
- 没有足够的 poi 舰队数据时会直接提示「poi 数据不可用」。

## 支持范围与限制

- 当前支持通常海域 1-1～1-6、2-1～2-5、3-1～3-5、4-1～4-5、5-1～5-6、6-1～6-5、7-1～7-5。
- 活动海域暂不支持。
- 部分资料无法给出可靠概率时会显示近似值；能动分歧需要玩家指定方向。
- 敌舰出现比例来自收集到的样本，不代表游戏中的官方遭遇概率。
- 导出功能暂不包含陆航、支援舰队和漩涡损耗设置，需要在目标模拟器中补充。
- 地图、规则和敌舰资料随插件提供；舰船头像在 poi 图片缓存不可用时可能请求游戏图片服务。
