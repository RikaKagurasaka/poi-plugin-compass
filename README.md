# poi-plugin-compass

舰队罗盘插件的通常海域 MVP。

当前版本已包含 poi 运行时代码、纯规则引擎和首批通常海域数据。目标功能是：针对用户选定的舰队（当前默认第一舰队），展示海图、带路条件、各分歧点的路线概率和全局路径概率，并允许未来录入能动分歧的手动路线覆盖。

## 当前结论

- 可行，但必须先建立统一的离线规范数据层；不建议让 poi 运行时直接依赖 Wiki、NGA 或 TsunKit 的可用性。
- poi 内置 `fcd.map` 适合作为地图几何和数字节点到字母节点的主来源。当前本地快照版本为 `2026/07/28/02`，包含 136 个海图条目。
- 带路规则应采用“来源快照 + 规则 AST + 置信度”的结构。无法求值时显示“未知”，不能把未知当成 0% 或随机。
- 敌舰实体统一用 master ID；敌方制空优先使用 TsunKit 已给出的门槛数组，同时保留敌舰装备 master ID 作为可复算和审计依据。
- 第一版应先覆盖通常海域和 1～2 张复杂测试图，再接入活动图、NGA 手工复核和外部模拟器导出。

## 当前实现

- `1-1`：完整录入起点到 A 点以及按舰队数量变化的 A 点分歧概率。
- `2-5`：录入常见出发点、B/C/E/F/G/I/L 等节点的规则；未覆盖或索敌值缺失时显示“未知”，不伪造概率。
- 地图几何从 poi 的 `fcd.map` 读取，UI 使用 SVG 绘制节点、边、当前节点和全局到达概率。
- 舰队状态从 poi 第一舰队和 master 数据读取；舰种、速度、运输桶和近似 33 式索敌可参与求值。
- 规则引擎支持条件 AST、规则优先级、概率传播和手动路线覆盖；手动覆盖只影响当前推演，不修改游戏状态。

## 工作边界

本仓库不会自动出击、替用户点击游戏，也不会在运行时为了显示信息抓取外部网站。通常海域规则目前通过 `data/maps.json` 离线维护；未来若加入刷新脚本，脚本应限速、保存原始响应摘要，并生成可审阅的规范数据。
